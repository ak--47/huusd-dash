# Cached primary sources

Copies of the public documents the site is built from, kept here so the numbers can be checked even if a link moves or a document is edited. Each file is a public record of the Harwood Unified Union School District (HUUSD) or the State of Vermont, or a consultant document presented to the HUUSD board in public.

This folder is **not** published to the website. The site cites the original online versions through `data/sources.js`; the "Key" column below is the source's key in that file.

Retrieved October 28-29, 2026. Text files (`.txt`) are plain-text exports or extractions of the original, made so the documents can be searched; where a table matters, check the original.
